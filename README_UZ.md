# 93 VPN — Android бошланғич лойиҳаси

Бу архив Android Studio орқали очиладиган **илова интерфейси прототипи**.

## Ҳозир нима бор?
- 93 VPN номи ва бошланғич дизайн
- Ўзбекча интерфейс
- Тил тугмаси (ҳозирча ЎЗ / RU / EN кўринишини алмаштиради)
- Автоматик танлаш, Германия ва Нидерландия серверлари рўйхати
- Сервер ҳали уланмагани очиқ кўрсатилади

## Муҳим
Бу ҳали ишлайдиган VPN эмас ва APK файл эмас. Реал VPN туннели, сервер конфигурацияси,
фойдаланувчи аккаунтлари, SMS тасдиғи, тўлов ва реклама интеграцияси қўшилмаган.
Шу сабабли у ҳозир интернет трафигини VPN орқали йўналтирмайди.

## APK йиғиш
1. Android Studio ўрнатинг.
2. `93-vpn-android` папкасини Android Studio'да очинг.
3. Gradle синхронизацияси тугашини кутинг.
4. Build → Build Bundle(s) / APK(s) → Build APK(s) ни танланг.
5. APK `app/build/outputs/apk/debug/` ичида пайдо бўлади.

## Кейинги техник ишлар
- VPN протоколи ва сервер томонини танлаш (масалан, WireGuard асосида)
- Германия ва Нидерландия VPS серверларини ижарага олиш
- Калитларни хавфсиз бошқариш ва автоматик сервер танлаш
- Android `VpnService` интеграцияси ва ҳақиқий туннел
- SMS/аккаунт API, 3 кунлик синов, 2 қурилма лимити
- Обуна ва тўлов провайдери
- Реклама SDK ва махфийлик сиёсати
- Юклама/трафик синови ва хавфсизлик текшируви
